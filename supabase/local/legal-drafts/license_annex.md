# Anexo de licencia del curso (borrador sin validez)

BORRADOR SIN VALIDEZ LEGAL. Este texto existe solo para construir y probar el envío a revisión en una base local. No es el texto que redacta el abogado, no obliga a nadie y no se publica.

Aquí irá el anexo por el que el maestro le da a la Plataforma la licencia de un curso determinado: el curso identificado, el carácter exclusivo, el plazo, el alcance, la contraprestación, el crédito, las garantías y qué pasa si el maestro se va.
